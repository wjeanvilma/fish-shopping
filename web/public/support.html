Features 2.0

Systems added across Finish 2.0 — sim stays 20 Hz; presentation never changes wages permanently.

Weather & tide

Weather and tide change catch weights and presentation. Check the HUD weather/tide strip; storms and festivals can stack temporary tips.

Festival weekends

Seasonal festival windows boost crowd and sale tips while active. The festival HUD banner is presentation; economy tips come from the event catalog.

Achievements & species journal

Achievements unlock from sim stats. The species journal/codex tracks logged fish from the HUD. Neither changes wages or prices.

Fishing mastery & staff trees

Mastery coaching tips and staff specialization branches sit on top of hire/upgrade rules. Staff schedules stay offline-friendly.

Contracts 2.0 & daily goals

Delivery chains and reputation-gated contracts sit beside classic quests. Daily goals / offline journal summarize progress after away time — claim from Goals.

Language & accessibility

Settings → Language supports English and Spanish for UI chrome. TalkBack/keyboard titles cover 2.0 panels; raise HUD text scale or enable reduced motion if needed.

Cloud offline queue

Failed cloud pushes queue the latest snapshot and flush on resume/online. Conflict UI asks when local and remote both look valid. Firestore rules are a reviewed snippet operators paste — not auto-deployed from CI.

Web checkout (local)

Without VITE_BILLING_API_BASE the web client uses a local entitlements stub. Point at the in-repo checkout-api emulator for sandbox restore/fulfill — never commit payment secrets.

Saves & recovery

  • Local slots keep a latest and previous backup.
  • If latest is corrupt, choose Recover previous on the title screen.
  • Private / blocked browser storage falls back to memory-only — progress is not durable until storage works.

Restore purchases

Lost a harbor unlock or cosmetic after reinstall? Use Restore purchases in Goals (or Cosmetics).

  1. Sign in to the same Play Store or web checkout account used for the purchase.
  2. Open the harbor, then Goals (or Cosmetics).
  3. Tap Restore purchases.
  4. Wait for the toast — entitlements grant idempotently (full harbor unlock + owned cosmetics).
  5. If nothing restores, confirm the SKU is owned in Play → Payments & subscriptions (or your web receipt email).

Covered SKUs: fish.full_harbor_unlock, cosmetics fish.cosmetic.*. Cosmetics are power-neutral.

Refunds

Android (Play)

Player self-serve: Play Store → profile → Payments & subscriptions → Budget & history → request a refund. Ops: Play Console → Order management → find order → Refund.

Google may auto-approve recent refunds; otherwise handle within Play policy windows.

Web checkout

Reply to the checkout receipt or email support with the order id. Ops refund in the checkout provider dashboard, then confirm Restore no longer returns the SKU.

After a refund, do not hand-edit save files — rely on store ownership + Restore.

Known issues

Private / blocked browser storage

Symptom: progress disappears after refresh. Workaround: allow site storage or leave private mode.

Corrupt latest save slot

Symptom: Continue fails or title shows recovery. Workaround: Recover previous on the title screen.

Cloud sync without Firebase keys

Symptom: Settings shows Cloud on, keys missing. Workaround: local play is fine; configure Firebase keys only if you need remote saves. Rules snippet is operator-applied.

Restore finds nothing

Symptom: toast says no purchases. Workaround: switch to the purchase account, then Restore again.

Frame stutter

Symptom: harbor feels choppy. Workaround: Settings → Quality → Low/Medium. Sim stays 20 Hz.

Ops 2.0 known issues

Cloud pending upload badge

Symptom: Settings shows pending upload after airplane mode. Workaround: reconnect — the offline queue flushes the latest snapshot on online/resume.

Locale covers UI chrome first

Symptom: some content names stay English after switching to Español. Workaround: expected for the i18n scaffold — UI chrome is localized; lore may follow later.

Web purchases stay stubbed

Symptom: web IAP never hits a real checkout URL. Workaround: set VITE_BILLING_API_BASE for emulator/production; leave blank for stub-only playtests.

Festival + weather tips stack

Symptom: sale prices look higher during an event. Workaround: check festival HUD and weather strip — tips are temporary catalog mults.

Performance

Lower Quality in Settings if frames stutter. The simulation stays fixed at 20 Hz; quality only changes presentation cost.
